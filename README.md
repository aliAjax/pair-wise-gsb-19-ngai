# hxwl-05 水族应急调度台

水族店停电、停水、过滤故障时的应急调度：异常登记开工单、鱼只暂养转移、维护师接单与恢复回缸、换水联动锁定。

## 技术栈

React + Vite + TypeScript + CSS（无新增依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能

- **异常登记**：登记鱼缸、原因（停电/停水/过滤故障）和开始时刻；同一鱼缸有未结工单时，新异常自动并入原工单
- **鱼只转移**：只匹配水质类型相同且尚有空位的暂养缸，位置不够时禁止捞鱼（页面禁用 + 记录层拒绝）
- **维护师接单**：接单必填维护师和预计恢复时刻；恢复后按当时转移的鱼只逐条确认回缸，全部回缸自动结案
- **换水联动**：工单未结的鱼缸在换水页不能完成换水

## 代码分层（src/emergency/）

- `types.ts` — 鱼缸、暂养缸、异常、工单、转移、换水记录类型
- `store.ts` — **记录层**：状态与全部动作（登记/接单/捞鱼/回缸/换水），业务规则在此兜底校验
- `occupancy.ts` — **占用判定层**：空位计算、候选暂养缸、能否捞鱼、鱼缸工单锁定的纯函数
- `DispatchPage.tsx` / `WaterChangePage.tsx` — **页面层**：应急调度台与换水页
- `time.ts` — 时刻格式化工具
