# hxwl-05 水族店应急调度台

停电、停水、过滤故障时的应急调度：异常登记 → 同水质暂养缸转移 → 维护师接单 → 恢复后逐条确认回缸；工单未结的鱼缸暂停换水。

## 技术栈

React + Vite + TypeScript + CSS（无新增依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能

- **异常登记**：记录鱼缸、原因（停电/停水/过滤故障）和开始时刻，自动生成工单
- **异常并入**：同一鱼缸已有未结工单时，新异常并入原工单，不重复开单
- **鱼只转移**：只找水质类型相同且尚有空位的暂养缸，空位不足则整体阻止捞鱼
- **维护师接单**：写明维护师与预计恢复时刻
- **逐条回缸**：恢复后按当时的转移记录逐条确认回缸，全部归位自动结案
- **换水限制**：工单未结的鱼缸在换水页无法完成换水（页面禁用 + 记录层双重拦截）

## 代码结构（记录 / 占用判定 / 页面 分层）

```
src/
  emergency/
    types.ts      # 领域类型：鱼缸、暂养缸、异常、工单、转移、换水
    seed.ts       # 初始数据（含一起处理中的演示工单）
    store.ts      # 记录层：状态、查询与全部变更动作
    occupancy.ts  # 占用判定：空位计算与转移方案（纯函数）
    format.ts     # 时刻显示与表单默认值
  pages/
    DispatchPage.tsx    # 应急调度台
    WaterChangePage.tsx # 换水页
  App.tsx         # 页面切换
```

工单状态流转：待接单 → 处理中 → 待回缸 → 已结案（无转移的工单恢复后可直接结案）。
